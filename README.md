# mos-riot-6532

The MOS 6532 RAM-I/O-timer.

| Crate | Registry |
|---|---|
| [`emu198x-mos-riot-6532`](crates/emu198x-mos-riot-6532) | [crates.io](https://crates.io/crates/emu198x-mos-riot-6532) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Atari 2600 and 7800.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
